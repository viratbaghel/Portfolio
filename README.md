
# Vipin Baghel Portfolio

A modern, animated, and responsive portfolio website built with **React.js** and **Tailwind CSS**. This project showcases my skills, experience, education, and projects in a visually appealing format.

## 🚀 Live Demo


## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- Vite
- EmailJS (for contact form)
- React Icons
- React Parallax Tilt
- React Toastify

## 📁 Features

- Responsive design for all devices
- Animated sections and interactive UI
- Modular React components
- Skills, Experience, Projects, Education, and Contact sections
- Contact form with EmailJS integration
- Social media links
